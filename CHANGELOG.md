# Changelog

## 0.1.4 — 2026-10-16

- Follow BB’s typography by default in formatted text and source editors.
- Add an optional 10–32 px font size override through **Aa** in the editor header, with English and Russian labels. The preference persists in this browser and updates open documents.
- Scale formatted code blocks with document text.

Thanks @yusuf8834 for suggesting this improvement in [#1](https://github.com/VKirill/bb-plugin-md-editor/issues/1) and for helping make Markdown PRO better!
